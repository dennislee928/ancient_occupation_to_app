## Full Description

Ancient Occupation Lab turns unusual historical jobs into modern mobile product experiments.

Inside the app are five interactive concepts:

- Whipping Boy: a consent-based accountability pact that makes follow-through feel social, not solitary.
- Royal Food Taster: a message firewall that filters high-pressure language before it reaches you.
- Sin Eater: a read-once confession ritual that ends in a symbolic purge.
- Nomenclator: a backstage memory prompt system for names, context, and social recall.
- Moirologist: a one-tap validation squad for moments when you need emotional support instead of advice.

This build is intended for early testers. It is a prototype experience designed to validate product direction, interaction patterns, and social dynamics.
