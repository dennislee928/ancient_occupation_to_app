# Documentation

This directory contains repo-owned documentation for the current Expo/React Native mobile shell and the five implemented concept demos from `spec_and_origin.md`.

## Files

- `architecture.md`: current app shell structure, verified module layout, and the feature module contract consumed by `App.js`.
- `backend-implementation-plan.md`: recommended backend architecture and phased delivery plan using Go, Ruby, Docker, and Supabase.
- `implementation-plans.md`: five concept-to-mobile plans that now serve as productization guidance beyond the current demos.
- `progress.md`: factual status snapshot based on the current filesystem and source files.

## Read Order

1. Read `progress.md` to understand what actually exists today.
2. Read `architecture.md` to see how the current shell and feature modules are wired.
3. Read `backend-implementation-plan.md` if you are moving from prototype to multi-user product.
4. Read `implementation-plans.md` for the next layer beyond the current prototype implementations.
