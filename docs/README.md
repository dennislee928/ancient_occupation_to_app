# Documentation

This directory contains repo-owned documentation for the current Expo/React Native mobile shell and the five planned product concepts from `spec_and_origin.md`.

## Files

- `architecture.md`: current app shell structure, verified module layout, and the feature module contract consumed by `App.js`.
- `implementation-plans.md`: five concise implementation plans, one per concept, reframed as iOS/Android mobile experiences.
- `progress.md`: factual status snapshot based on the current filesystem and source files.

## Read Order

1. Read `progress.md` to understand what actually exists today.
2. Read `architecture.md` to see how the current shell is wired.
3. Read `implementation-plans.md` to extend each concept into a shippable mobile feature.
